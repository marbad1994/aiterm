what it does

🎤 Voice — speaks back

Always-on mic via VAD. Speak naturally, pause to send. Kokoro TTS reads responses aloud sentence-by-sentence so the first word plays in under a second. Say stop to interrupt mid-sentence. 28 voices, all local, no API.

🎲 A different voice every few hours

shmakk rotates through all 28 Kokoro voices on a deterministic daily schedule — changes every 2 to 5 hours, timed differently each day. No randomness at runtime, no state. Just a hash of the date. Feels alive, costs nothing.

Typo correction

Deterministic, no API call. Uses your machine's command history and probability to fix typos the way you type, not some generic model.

Chat in shell

Just write. Ask questions, get answers, run suggested commands — all without leaving the terminal. Session history is preserved until you --compact.

Project scaffolding

Describe what you want in plain English. shmakk plans, creates dirs, writes files, asks before anything risky. Subagents spawned automatically for parallel work.

Skills

Workspace and global registries. Install from a URL, list categories, load exactly the skill a session needs.

Vim mode

Wrap real vi/vim, keep your config, and add :G, :Tw, :Cmd, plus full-block suggestions.

MCP

Connect stdio MCP servers as agent tools. Per-tool safety classification, env interpolation, status inspection.

SSH

Named remote hosts for ssh_run, ssh_push, and ssh_pull. Key auth and safety prompts stay in place.

Endpoints

Configure main for quality and fast for low-latency tasks like Vim suggestions.

Self commands

Control shmakk from inside the session: show plan, mcp status, set model, review edits.

Runtime profiles

tiny · balanced · deep · builder. Switch live with --profile-set. Context budgeting and loop-stall protection built in.

Safety

Risky commands always confirm before running. Secrets (.env, tokens, keys) are never sent to the AI. Defensive handling for fallback tool-call formats.
